# UI Baseline P0-A1.1

## Glass2
- Header: category + item index.
- Body: max 2 lines, static.
- Rotation: every 5000 ms.
- No marquee / ticker.
- Footer: replaceable persistent information slot.
- PTT freezes the current info item.

## StickS3 LCD
- Role: interaction screen, not news screen.
- Character-first UI.
- Idle micro-animation: blink.
- Listening / Thinking / Speaking / Success / Error each has a distinct facial state.
